# Slate

Slate is an independently versioned, local-first Markdown viewer plugin.

Choose the private Slate folder containing `slate.config.json`. The configuration
can name any number of absolute Markdown files and their supported views. Slate
reads and watches only those declared files; it does not copy their contents
into Workshop or synchronize them. For the full configuration contract and
supported views, use the [Slate README](https://github.com/LindsayB610/slate).
